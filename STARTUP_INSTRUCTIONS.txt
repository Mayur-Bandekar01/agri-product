===================================================================
                      HOW TO START
===================================================================

METHOD 1: Using the Batch File (Easiest)
-----------------------------------------
Double-click: start-backend.bat

METHOD 2: Manual Start
----------------------
1. Open PowerShell/Command Prompt
2. Navigate to backend folder:
   cd "e:\agri project\adinath-agri-services-project (2)\adinath-agri-services-project\adinath-agri-services\backend"

3. Activate virtual environment:
   .\venv\Scripts\Activate.ps1    (PowerShell)
   OR
   venv\Scripts\activate.bat       (Command Prompt)

4. Start the server:
   python -m uvicorn app.main:app --reload --host 127.0.0.1 --port 8000

===================================================================
                     TROUBLESHOOTING
===================================================================

Problem: "Module not found" error
Solution: Make sure virtual environment is activated (you should see (venv) in your terminal)

Problem: "Port already in use"
Solution: Another process is using port 8000. Either:
  - Stop the other process
  - Or change port: python -m uvicorn app.main:app --reload --port 8001

Problem: Frontend not loading
Solution: 
  - Check that backend is running on http://localhost:8000
  - Clear browser cache
  - Try incognito/private browsing mode

Problem: Database errors
Solution: Database file is at: backend/adinath.db
  - Backups are in: backend/backups/
  - To restore, copy a backup file to backend/adinath.db
